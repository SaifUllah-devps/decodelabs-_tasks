# Rule-Based AI Chatbot

## Project Overview
This project is a simple rule-based chatbot developed in Python as part of Project 1 of the DecodeLabs Artificial Intelligence Industrial Training Program.

The chatbot simulates a basic conversation by matching user inputs against predefined conditions and providing appropriate responses using `if-elif-else` statements.

## Features
- Responds to common greetings such as hello, hi, and hey.
- Answers predefined questions.
- Provides a response to unknown inputs.
- Runs continuously until the user exits.
- Supports exit commands such as bye, goodbye, exit, and quit.
- Handles uppercase and lowercase input.

## Technologies Used
- Python 3
- Conditional statements (`if`, `elif`, `else`)
- `while` loop
- User input and console output

## How to Run

1. Install Python 3 on your computer.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the following command:

```bash
python chatbot.py
```

## Example Interaction

```text
Chatbot: Hello! Welcome to my chatbot.
Chatbot: Type 'bye' or 'exit' to end the conversation.
You: hello
Chatbot: Hello! How can I help you?
You: what is ai
Chatbot: AI stands for Artificial Intelligence.
You: bye
Chatbot: Goodbye! Have a great day.
```
